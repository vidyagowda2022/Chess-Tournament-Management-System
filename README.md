# Implemented a Chess Tournament Management System with features for player management, tournament creation, player assignment, match generation, and leader board tracking. Built using HTML, CSS, and JavaScript with dynamic DOM updates and structured data handling.

# Chess Tournament Management System

## Features
- Add, edit, delete players
- Create and manage tournaments
- Assign players to tournaments
- Generate matches with random winners
- Leader board based on scores

## Tech Used
- HTML
- CSS
- JavaScript

Open index.html in browser
